# Portfolio - Abdel Karim Doudey

Portfolio personnel développé avec React, présentant mes projets, mes compétences et mes informations de contact.

## 🚀 Technologies utilisées

- React
- CSS
- React Intl (multi-langue)
- React Scroll
- AOS (Animate On Scroll)

## 📦 Installation

Clone le repository :

```bash
git clone https://github.com/AbdelKarim-Ensi/portfolio-Akd.git
cd portfolio-Akd
```

Installe les dépendances :

```bash
npm install
```

Lance le projet en local :

```bash
npm start
```

Le site sera accessible sur [http://localhost:3000](http://localhost:3000).
